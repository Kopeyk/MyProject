# MyProject

Навчальний проєкт для лабораторної роботи 6 «Налаштування CI/CD для автоматизації збору метрик, статичного аналізу коду і код-рев'ю».

- `src/myproject` – код (обробка оцінок студентів);
- `tests` – тести pytest;
- `.github/workflows/ci.yml` – конвеєр GitHub Actions: тести, перевірка код-рев'ю, Cloc, SonarQube Cloud, flake8 і Black через Reviewdog.
